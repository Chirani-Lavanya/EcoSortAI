## 📷 Features
## 🌍 EcoSort AI Features

- ♻️ **Waste Identification** – Detect the waste item from image or PDF  
- 📂 **Waste Classification** – Categorize into plastic, paper, organic, etc.  
- ✅ **Recyclability Check** – Identify whether the item is recyclable  
- 🇱🇰 **Sri Lanka Disposal Guide** – Provide correct local disposal method  
- 🌱 **Environmental Impact** – Explain how the waste affects the environment  
- ♻️ **Reuse Ideas** – Suggest creative ways to reuse items  
- 💡 **Eco Tips** – Provide sustainability tips (e.g., avoid single-use plastics)  
- 📷 **Image Upload Support** – Analyze JPG/PNG images  
- 📄 **PDF Analysis** – Extract and analyze waste-related content from PDFs  
- 🎯 **SDG 12 Focus** – Supports Responsible Consumption & Production  

Supports intelligent waste analysis using image and document inputs for sustainable decision-making.
